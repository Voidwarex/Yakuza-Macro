FAQ

Questions people ask

What do I need to run it?

A Windows 10 or 11 PC. The app opens its dashboard in your normal web browser. For controller mode you also install the free ViGEmBus driver once, which the setup handles for you.

Can I use my account on another PC?

Accounts lock to the first PC they sign in from. If you get a new PC, contact support and we'll reset your hardware lock so you can sign in there.

Does it work with PlayStation controllers?

Yes, when Steam Input or DS4Windows is running. They make the pad appear as an Xbox controller, which is what Yakuza reads. Xbox controllers work as they are.

What happens when my time runs out?

The macros switch off and your settings stay saved. Redeem another key and they're back on straight away.

If I buy a key during a free weekend, do I lose time?

No. Keys redeemed during an event only start counting down once the event ends.

Is it safe to use in my game?

Yakuza sends ordinary key and controller presses, the same as you pressing them. Some games don't allow macros in their rules, so check the rules of any game you play before using it.
